# Torneo Twenty-One

Pequeño programa de consola escrito en Scala que simula dos rondas de un
torneo de Twenty-One. Muestra el estado de cada mano, cuenta las manos
válidas y las que hacen `bust`, y compara la mejor puntuación de cada ronda.

## Requisitos

- Java 8 o superior
- sbt

## Ejecutar

Desde la raíz del proyecto:

```bash
sbt run
```

El programa utiliza Scala `2.12.21`, configurado en [build.sbt](./build.sbt).
